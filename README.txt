Sri Nidhi Electrical and Sanitary website

Main file: index.html
Assets: Product and installation images are loaded from their image-hosting URLs.

How to publish:
1. Create a GitHub repository named sri-nidhi-electrical-and-sanitary.
2. Upload index.html and the assets folder (if you later add local images).
3. Import the repository into Vercel or enable GitHub Pages.
4. The WhatsApp enquiry form opens a pre-filled message; the customer must press Send.
5. GPS location sharing works only when the deployed site is served over HTTPS and the customer grants permission.

Business service areas shown:
- Building electrical and plumbing work: Jagtial district.
- CCTV and water purifier installation/service: Jagtial and Karimnagar districts.
